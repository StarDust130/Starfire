# Contributing to Starfire

## Branches

Use:

- `feature/<name>`
- `fix/<name>`
- `refactor/<name>`
- `docs/<name>`
- `test/<name>`

## Commits

Use Conventional Commit style:

- `feat:`
- `fix:`
- `refactor:`
- `test:`
- `docs:`
- `chore:`
- `ci:`
- `perf:`

Examples:

`feat: add open app tool`

`fix: handle failed app launch`

`test: add tool executor tests`

`chore: configure biome`

## Pull requests

Keep changes focused.

Every PR should pass:

- formatting
- linting
- type checking
- tests
