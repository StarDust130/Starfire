# 🌐 VERCEL ECOSYSTEM

Use the Vercel ecosystem where it makes Starfire better.

```text
                         ⭐ STARFIRE
                              │
                 ┌────────────┴────────────┐
                 ↓                         ↓
              ☁️ eve                  💻 Desktop
                 │                         │
        Agent infrastructure        OS capabilities
                 │
       ┌─────────┼──────────┬───────────┐
       ↓         ↓          ↓           ↓
  🤖 AI SDK  💰 Gateway  ⏰ Workflow  🔌 Connect
       │         │          │           │
       ↓         ↓          ↓           ↓
    Models    Routing    Background   Services
                              │
                              ↓
                         📦 Sandbox
                              │
                       Isolated execution
```

### What each one does

**☁️ eve**

The agent framework.

**🤖 AI SDK**

Talk to different AI models through one interface.

**💰 AI Gateway**

Model routing, providers, and cost/performance optimization.

**⏰ Workflow**

Durable background workflows when Starfire needs work to continue over time.

**🔌 Connect**

Connect Starfire to services like Gmail, Calendar, Slack, etc.

**📦 Sandbox**

Safe isolated environments for future computer/cloud execution.

**🌐 Browser / Playwright**

Future browser automation.

**🏠 llama.cpp**

Future local model execution.
