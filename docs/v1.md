# ⭐ Starfire V1

> **Build a desktop AI that doesn't just talk — it understands you, remembers you, sees your computer, thinks, acts, and helps you get things done.** 🧠⚡

Starfire is a **personal AI companion for your computer**.

It is not just:

```text
❌ A chatbot that only answers questions

❌ An agent that only does exactly what you ask

❌ A collection of random tools
```

Starfire is designed to become a system that:

```text
👂 Listens
   ↓
👀 Sees
   ↓
🧩 Understands
   ↓
💾 Remembers
   ↓
🤔 Thinks
   ↓
🖐️ Acts
   ↓
📚 Learns
   ↓
❤️ Stays with you
```

The goal is simple:

> **Build an AI that understands you, helps you work, handles boring tasks,
> remembers what matters, and becomes more useful over time.**

---

# 🌌 What Is Starfire?

Starfire is the **product and the companion**.

You talk to Starfire.

Starfire can:

```text
🎤 Talk with you
🧠 Understand your goals
💾 Remember important things
👀 Understand your screen
🖥️ Control your computer
🔎 Find information
🤝 Delegate complex work
⏰ Manage tasks and reminders
💡 Suggest useful things
🤖 Work in the background
❤️ Maintain continuity with you
```

The long-term vision is closer to:

> **"An AI living beside your computer."**

Not:

> "Ask me a question and I will answer."

---

# 🧠 The Core Idea

Starfire has **one user experience** with two execution paths:

```text
                         ⭐ STARFIRE
                              │
                 ┌────────────┴────────────┐
                 │                         │
            ⚡ FAST PATH               🧠 DEEP PATH
            Realtime Voice               Eve Worker
                 │                         │
          talk + basic work          complex/background work
                 │                         │
                 └────────────┬────────────┘
                              │
                   🧩 Shared Capabilities
                              │
                     💪 Platform Layer
                              │
                         💻 Computer
```

### ⭐ Starfire = the companion

The user interacts with Starfire.

### ⚡ Realtime Voice = the fast path

Used for:

```text
💬 Conversation
🛠️ Basic actions
👀 Quick questions
⚡ Immediate interaction
```

### 🧠 Eve = the background worker

Used when Starfire decides that a task is better handled as:

```text
🔎 Deep research
🌐 Multi-step browsing
💻 Complex workflows
🔁 Long-running work
🤖 Background work
```

The user never needs to think about Eve.

The user talks to **Starfire**.

# 🤝 Starfire + Eve

The relationship is simple:

```text
⭐ Starfire
  = Companion + Coordinator

🧠 Eve
  = Background Worker
```

Example:

```text
User:
"Open Discord."

        ↓

⭐ Starfire
        ↓
open_app()
        ↓
💻 Discord opens
```

Complex example:

```text
User:
"Research the best AI startups hiring interns
and make me a shortlist."

        ↓

⭐ Starfire
        ↓
delegate_task()
        ↓
🧠 Eve
        ↓
Deep work
        ↓
✅ Result
        ↓
⭐ Starfire
        ↓
User gets the answer
```

If Eve needs the user:

```text
🧠 Eve
   ↓
Needs information
   ↓
⭐ Starfire
   ↓
asks user
   ↓
👤 User answers
   ↓
🧠 Eve continues
```

The user always talks to Starfire.

# 📜 One Source of Truth

Every Starfire capability has **one canonical definition**.

The definition contains things such as:

```text
name
description
arguments
schema
metadata
```

The same definition can be used to create the format needed by:

```text
⚡ Realtime Voice
🧠 Eve
🧪 Evaluation
```

So we do not manually maintain multiple copies of the same tool schema.

```text
             🧩 Capability Definition
                       │
              ┌────────┴────────┐
              ↓                 ↓
         🎤 Voice            🧠 Eve
              │                 │
              └────────┬────────┘
                       ↓
                Shared Dispatch
```

# 🖥️ Platform Independence

Starfire should not be tied to Linux forever.

The architecture is designed so the capability stays the same while the
platform implementation changes underneath it.

```text
             open_app
                 ↓
        Starfire Capability
                 ↓
              Port
        ┌────────┼────────┐
        ↓        ↓        ↓
      Linux   Windows   macOS
```

This means adding Windows or macOS should not require rewriting:

```text
❌ Starfire personality
❌ Memory
❌ Context
❌ Eve
❌ Voice logic
❌ Capability definitions
```

Only the platform implementation should change.
