# 🔐 Security

Found a security issue in Starfire?

Please **don't open a public issue** with sensitive details.

Instead, report it privately so it can be investigated and fixed safely.

## 🐛 Report a Vulnerability

Open a private security report through GitHub's **Security Advisories**.

Please include:

- What happened
- How to reproduce it
- Which part of Starfire is affected
- Any relevant screenshots or logs

## ⚠️ Please Don't

- Post secrets, API keys, passwords, or tokens
- Publish an exploit before it is fixed
- Test on someone else's machine

Thanks for helping keep Starfire safe. 🫂
